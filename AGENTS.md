# AGENTS.md

Сайт это стенд шага «Форма на сайте» проекта `projects/ru/ai_engineer_booking_automation_project` в hexlet-exercise-kit. Шаг ссылается на адрес сайта и на тексты полосы стенда, поэтому правка сообщений в `src/api.ts` проверяется по тексту шага.

Консультанты в `src/consultants.ts` повторяют `code/consultants.json` проекта. Правка одного без другого даёт студенту консультанта, которого функция никогда не выберет.
